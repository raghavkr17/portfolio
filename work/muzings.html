The app

An assistant that remembers stuff so you don't have to.

Muzings has two main parts. Capture, where you tell it something. And recall, where you ask for it back later.

Both have to feel easy. That makes them pretty tricky to test.

Check out muzings.ai

What I do

I help with product and quality. The part I own is testing new features.

I write test cases, run them on the live app, and keep track of issues that keep showing up. That way the engineers can fix the actual cause, not just the one bug.

How I test

  • Use the real app. I test it the way a real person would use it.
  • Test both halves. Capture and recall on their own, then together. A lot of bugs hide in the handoff.
  • Look for patterns. One bug is a bug. The same bug three times is a pattern worth fixing.
  • Ask the simple question. Would this feel right if I were the user?

Why I like it

AI apps live or die on trust. If you tell it something and it gets it wrong later, you stop using it.

Testing like a user while thinking like an engineer is exactly the mix I'm going for with HCDE.
