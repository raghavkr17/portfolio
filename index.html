02How I work

HCDE taught me to ask who it's for. Engineering lets me answer with something real. Every project on this page went through these four moves.

  1. 01

    Listen

    Start with the person, not the feature. SeniorGuard was shaped around elderly users who should barely notice it and caregivers who need signal, not noise.

    SeniorGuard · Mitcham vendors
  2. 02

    Shape

    Turn what I heard into flows and forms. Mitcham's reserve → code → pickup loop is three steps because someone is walking to a shop that's about to close.

    Mitcham · AirPods case · acadAI brand
  3. 03

    Build

    Own it end to end. API, auth, migrations, admin tools, firmware, dashboards. The details users feel usually live in the code, so I don't hand them off.

    Mitcham · SeniorGuard · Amma Childcare
  4. 04

    Prove

    Test it like it's live, because it is. At Muzings I design test cases, run them against the real product, and track recurring issues so engineering fixes causes, not symptoms.

    Muzings · 99%+ uptime
