02How I work

HCDE taught me to start with people. Engineering lets me actually ship the thing. Pretty much every project goes like this.

  1. 01

    Listen

    Talk to the people first. For SeniorGuard that meant older folks who shouldn't have to think about it, and caregivers who just want to know if something's wrong.

    SeniorGuard · Mitcham
  2. 02

    Shape

    Find the simplest flow. Mitcham is reserve, get a code, pick it up. Three steps, because you're probably walking to a shop that's about to close.

    Mitcham · AirPods · acadAI
  3. 03

    Build

    I build the whole thing. API, login, database, admin tools, firmware. A lot of what users actually notice ends up living in the code.

    Mitcham · SeniorGuard · Amma
  4. 04

    Test

    Test it like it's live, because it is. At Muzings I write test cases, run them on the real app, and keep track of what keeps coming back.

    Muzings
